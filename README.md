# Ai.Brill.Movies

ספריית סרטי AI בעברית, מותאמת לנייד. HTML, CSS ו-JavaScript בלבד. אין build, שרת, הרשמה, מפתח API או תלות חיצונית.

## הפעלה ב-GitHub Pages

אחרי מיזוג ה-PR:
1. פתחי את Settings של הריפו ובחרי Pages.
2. ב-Build and deployment בחרי Source: Deploy from a branch.
3. בחרי branch: main, folder: / (root), ואז Save.
4. אחרי סיום הפריסה, הקישור המאומת לאתר יופיע ב-Pages תחת Visit site.

לא צריך להפעיל Pages בפורק. ההגדרה נעשית בריפו שלך פעם אחת. מיזוגי PR נוספים יתעדכנו באתר דרך אותה פריסה.

## הוספת סרטים

המידע נמצא ב-`films.json`. עדכונים חדשים מגיעים כ-PR מהפורק; בעלת הריפו בודקת וממזגת. אין באתר מנגנון שמחפש או מוסיף סרטים בעצמו.

לכל סרט: `id` ייחודי, `title`, `creator`, `added` בפורמט YYYY-MM-DD, `tools` (או null כשלא אומת), `category`, `description` בעברית, `watchUrl`, `sourceUrl`, ואופציונלית `poster` לתמונה מהמקור ו־`posterFallback` לתמונה חלופית אם הראשית אינה זמינה. לא משנים IDs קיימים. לפני הוספה בודקים כפילויות לפי שם וקישור. תאריך `added` הוא מועד ההוספה, לא שנת ההפקה.

קטגוריות: פסטיבל, קהילה, הדגמה רשמית. השתתפות בפסטיבל אינה הוכחה לכלי יצירה מסוים. כשלא ידוע כלי, נשאיר null במקום לנחש.

`durationSeconds` הוא אורך הסרט בשניות, או `null` כשטרם אומת. לדוגמה, 110 מוצג כ־1:50. אין להזין הערכות כאילו היו משכים מאומתים.

`durationSource` שומר את מקור משך הצפייה של הגרסה המקושרת. נתוני 32 הסרטים שולבו מ־PR #4 (22 הסרטים הראשונים) ומ־PR #5 (עשרת סרטי 9.10.2026). המשכים מוצגים לצד התמונות; גרסאות אחרות של אותו סרט עשויות להיות באורך שונה.

## תמונות, פריימים ובחירות אישיות

לחיצה על תמונת סרט פותחת את קישור הצפייה. הכפתור ״בחירת פריים ומשך״ פותח חלון עריכה: בסרטי YouTube אפשר לבחור בין שלוש תמונות פריימים שהשירות מספק. לבחירת רגע מדויק, טוענים קובץ וידאו מקומי, עוצרים ברגע הרצוי ובוחרים את הפריים. אפשר גם לבחור צילום פריים שכבר נשמר במכשיר. הווידאו אינו עולה לשרת; רק תמונת הפריים שנבחרה נשמרת בדפדפן. טעינת קובץ וידאו ממלאת משך חסר מתוך הקובץ, ואפשר לתקן אותו ידנית.

הבחירות האישיות נשמרות ב־IndexedDB בדפדפן ובמכשיר הנוכחיים. הן אינן משנות את `films.json` או מסתנכרנות בין מכשירים. ב״הבחירות האישיות שלי״ ניתן לייצא קובץ גיבוי ולטעון אותו במכשיר אחר; הייבוא מחליף בחירות לסרטים שבגיבוי ומשמר את שאר הבחירות. מחיקת נתוני האתר בדפדפן מוחקת גם את הבחירות המקומיות. שינוי ברירת המחדל לכל המכשירים נעשה ב־`films.json` ופרסום עדכון לאתר.

YouTube אינו מאפשר לדף חיצוני ללכוד פריים שרירותי מתוך הנגן שלו. הבחירה המקוונת מוגבלת לתמונות הפריימים הזמינות; לכידה בזמן מדויק דורשת קובץ וידאו מקומי או צילום פריים שנשמר מראש.

`film-images.js` מעדיף את הרזולוציה הגבוהה ביותר הזמינה של אותו פוסטר או פריים: maxres, SD, HQ, MQ ורק לבסוף תמונה קטנה. גם בחירות YouTube ישנות שנשמרו כ־120×90 משודרגות לתמונה גדולה של אותו פריים כאשר היא זמינה. תמונות מציינות־מקום של YouTube אינן נחשבות לתמונות חדות, ותמונות קטנות אינן נמתחות מעבר לגודלן. לכידת פריים מקובץ מקומי שומרת עד 1920 פיקסלים, בגבולות הרזולוציה המקורית של הקובץ.

## בדיקה מקומית

האתר מעוצב כמחברת: דף הפתיחה כולל תוכן עניינים, מקרא וקישורים לסרטים שנוספו לאחרונה. הלשוניות מובילות לכל האוסף, לסרטי פסטיבלים, ליצירה מהקהילה ולהדגמות כלים. בכל עמוד אפשר לחפש ולמיין; אפשר גם לשמור קישור ישיר לעמוד או לסרט.

לשונית ״חדש״ מציגה את כל הסרטים מתאריך ההוספה האחרון באוסף, גם כשהם משתייכים לקטגוריות שונות. כעת אלו עשרת הסרטים מ־PR #5, שנוספו ב־9.10.2026. עם הוספת קבוצה חדשה בתאריך מאוחר יותר, הלשונית מתעדכנת אוטומטית; הסרטים הקודמים נשארים באוסף ובקטגוריות שלהם.

מספרי הסרטים והתוספות האחרונות מתעדכנים אוטומטית מתוך `films.json`. מוסיפים סרטים בסוף הרשימה עם תאריך `added` מתאים; כשכמה סרטים נוספו באותו יום, הסרט שנוסף אחרון ברשימה יופיע ראשון. לסרט ללא פוסטר, או כשהפוסטר אינו זמין, מוצגת כריכה טיפוגרפית.

העיצוב נמצא ב־`style.css`, והניווט והצגת הסרטים ב־`script.js`. גופני Heebo ו־Amatic SC כלולים מקומית ב־`assets/fonts` יחד עם רישיונות ה־OFL שלהם, ולכן אין צורך בשירות גופנים חיצוני.

```sh
python3 -m http.server 8000
```

פתחו localhost:8000. לא לפתוח ישירות כ-file: משום שהמידע נטען מ-JSON.

בדיקה של הרשימה והקישורים:

```sh
python3 validate.py
```

## תוכן וזכויות

10 הסרטים הראשונים נוספו ב-8.10.2026. התקצירים מבוססים על העמודים המקושרים בכל כרטיס; סרטי הפסטיבל על חדר ההקרנה הרשמי של Runway. קישורים ותוכן עמודים נבדקו; אין כאן טענה לביקורת צפייה מלאה. הפוסטרים של סרטי הפסטיבל נלקחו מעמוד האוצרות הרשמי ומיוחסים לו באתר. הסרטים שייכים ליוצרים ומוצגים דרך קישורים בלבד.
